# 🧠 Multilingual Lexical Analyzer for Java, C, and C++

This project implements a **Multilingual Lexical Analyzer** that supports tokenization and analysis of **Java**, **C**, and **C++** source code. It was developed as part of a published research paper.

📄 **Published Paper:**  
**"Implementing a Multilingual Lexical Analyser for Java, C and C++"**  
Available on IEEE Xplore: [https://ieeexplore.ieee.org/document/10923959](https://ieeexplore.ieee.org/document/10923959)

---

## ✨ Features

- 🔤 Supports Java, C, and C++ lexical analysis
- 🧩 Detects keywords, identifiers, operators, literals, symbols, and more
- 📑 Language detection based on file extension
- 🗂 Output is well-structured with token classifications

---

## ⚙️ How to Run

**Input File:**
You'll be prompted to enter the path to a `.java`, `.c`, or `.cpp` file for analysis.

---

## 🧪 Sample Output

```
Language detected: C++
Token: #include -> Preprocessor Directive
Token: <iostream> -> Header File
Token: int -> Keyword
Token: main -> Identifier
Token: ( -> Symbol
Token: ) -> Symbol
...
```
